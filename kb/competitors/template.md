# Competitor: Template

Audience: Internal, approved for caller-facing paraphrase.
Effective date: 2026-05-17

Replace this file with one file per competitor.

Suggested structure:
- Summary of the competitor.
- Where they are strong.
- Where your company is strong.
- Best-fit customer profile.
- Pricing comparison, if approved.
- Migration or integration notes.

Rules:
- Stay factual and professional.
- Do not disparage competitors.
- If facts are uncertain or outdated, say that the agent should offer follow-up.
